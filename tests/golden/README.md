# Golden CVNSS4.0 reference tests

`decode.tsv` was generated with `tools/generate_rules.js` using the supplied
`tools/cvnss4_converter_audit_safe.js` (5.0.0-audit-safe). Fields are raw code
and canonical Unicode. 825 examples include all 810 distinct CVSS rime codes and
15 targeted words/sentences/case tests. Additional linguistic validation and
context ambiguity tests are future work.
